# Netflix Clone

A responsive Netflix landing page clone built using HTML and CSS.

## About The Project

This project is a front-end clone of the Netflix homepage created to practice web development fundamentals such as HTML, CSS, Flexbox, positioning, responsiveness, and Git/GitHub workflows.

## Features

* Responsive navigation bar
* Netflix-inspired hero section
* Background image with overlay
* Email subscription form
* Mobile-friendly layout
* Clean and modern UI

## Technologies Used

* HTML5
* CSS3
* Git
* GitHub

## Learning Outcomes

Through this project, I learned:

* Semantic HTML structure
* CSS Flexbox
* Positioning (relative and absolute)
* Responsive design principles
* Git and GitHub version control
* Project organization and deployment workflow
